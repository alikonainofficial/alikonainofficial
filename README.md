## Case files

### [AI ad pipeline](https://alikonainofficial.github.io/work/ai-ad-pipeline/) · Speechify

Speechify's marketing team was making AI ads by hand, at roughly four hours each. I led the move to an internal app with 21 ad-format pipelines that can produce up to 15 ads in ten minutes. About 10,000 ads so far, with the marketing team running it themselves.

### [The 300,000-book pipeline](https://alikonainofficial.github.io/work/books-pipeline/) · Speechify

Python tooling that collected 300,000+ public-domain books for a new book-listening app and handled their metadata, audio, subtitles, topics and genres. None of them opened by hand.

### [BookTok](https://alikonainofficial.github.io/work/booktok/) · Speechify

A book-reading app, live at [booktokapp.com](https://booktokapp.com/), built on Supabase with Row Level Security and Edge Functions doing the heavy lifting.

### [PubGuru Ad Inspector](https://alikonainofficial.github.io/work/pubguru-ad-inspector/) · MonetizeMore

A Chrome extension that shows website publishers why an ad isn't behaving. I worked on its redesign, built the ad overlay for debugging, and fixed the setup bugs publishers kept reporting.
