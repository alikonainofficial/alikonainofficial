### [Book Topics Assigner](https://github.com/alikonainofficial/book-topics-assigner)

A Python tool that assigns topics to book descriptions using the OpenAI API. Supports CSV input and output, resumable processing, and retry handling.

### [Books Recommender](https://github.com/alikonainofficial/books-recommender)

A Python recommendation project using reading history and book metadata, with Supabase integration for user data and recommendation storage.
